# Archived extraction plan

The original extraction is complete. This sanitized historical record retains only the decisions that
remain relevant to the public architecture:

1. Python owns the canonical CLI, MCP server, provider-neutral runtime and REST Gateway.
2. TypeScript packages are thin pi and experimental dsh adapters over canonical interfaces.
3. The repository has independent tests, builds, releases and protected-branch delivery.
4. Product facts are consumed through versioned HTTP APIs; product source code and storage are not
   dependencies.
5. Intelligence results are advisory and never authorize broker, database, Git hosting or repository
   mutations.

Implementation details, private repository coordinates, workstation paths and one-time environment
evidence were intentionally removed. Current work is governed by active OpenSpec changes and
`docs/handoffs/CURRENT.md`.
